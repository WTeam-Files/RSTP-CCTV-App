What is archived where

  1. Phone
    Last 3 hours of snapshots.

    A still image is stored every few seconds, then deleted automatically once it is older than 3 hours (or when the frame cap or free-space floor is hit). This is a short safety buffer, not an archive.

  2. Phone
    Detection events for 72 hours.

    Motion and object detections keep their own snapshot and optional clip, separate from the 3 hour buffer.

  3. Home server
    Long-term history.

    Your home server pulls footage from this phone on its own schedule and keeps it. This page cannot see that server, so it cannot confirm the last pull. If the phone's buffer looks healthy but you want proof, check the server.
